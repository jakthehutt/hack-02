## What it was cited for

The project's self-description. EUvsDisinfo is the flagship project of the EEAS East StratCom Task Force, set up in 2015 to better forecast, address and respond to disinformation campaigns affecting the European Union, and it maintains what is generally described as the largest open repository of pro-Kremlin disinformation cases, each carrying an expert verdict of credible or disinformation.

Cited to make the provenance of our candidate ground truth explicit: the labels come from an EU institutional body with a stated counter-disinformation mission, which is a relevant consideration when the labels are used as scientific ground truth. Researchers also report that the database is not published in an analysis-ready form and has typically had to be scraped, which is a practical cost to plan for. A claim surfaced in search results that an EUvsDisinfo MCP server exists for programmatic access; this was not verified and should not be relied on.
