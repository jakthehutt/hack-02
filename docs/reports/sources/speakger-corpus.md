# SpeakGer: A meta-data enriched speech corpus of German state and federal parliaments

- **URL:** https://arxiv.org/html/2410.17886v1
- **Publisher / venue:** arXiv preprint
- **Retrieved:** 2026-09-26
- **Cited in:** 2026-09-26-narrative-early-warning-prior-art.md §5

## What it was cited for

A speech corpus covering both the German federal parliament and the German state parliaments, with speeches enriched by speaker and session metadata.

Cited only as the extension path: if the Austrian pipeline works, the equivalent German federal and state layers are already available as a corpus, so scaling beyond Austria is a data-integration task rather than a new collection project.
