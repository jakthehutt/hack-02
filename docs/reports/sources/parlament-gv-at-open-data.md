## What it was cited for

The Austrian Parliament's open-data description for the stenographic records of the Nationalrat and Bundesrat. It documents the metadata available for each protocol — session number, session date, links to the HTML protocol and to the session record — describes the metadata schema in JSON, and states that result lists from the filter and API for the stenographic records are published under the Creative Commons Attribution 4.0 licence.

Cited as the legally clean, machine-readable route to current Austrian parliamentary speech, covering the years ParlaMint-AT does not reach.
